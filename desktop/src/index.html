ChatGPT Exporter Desktop

Installs the exporter userscript into your browser. The exporter itself stays a userscript — this window is only the installer.

1. Install a userscript manager

A manager extension is what actually runs the exporter on chatgpt.com. Skip this step if you already have one.

2. Hand it the script

Opens your browser at a local address serving the bundled script. Your manager recognises the .user.js address and shows its own install page — nothing is installed without you confirming there.

What this app does not do

  • It never reads your browser profile, cookies, history or session — so it cannot tell you whether a manager is already installed, and does not try.
  • It never signs in to ChatGPT and never sees your conversations. Exporting happens in the browser, in the userscript, as it always did.
  • It writes nothing into a browser or an extension. Your manager's own install prompt is the only thing that installs the script.
  • The local address is bound to 127.0.0.1, serves this one script at one unguessable path, and stops when you quit.
